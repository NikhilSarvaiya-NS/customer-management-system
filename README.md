# Customer Management System

A web-based customer and quotation management system developed using PHP and MySQL.  
The application helps manage customer records, generate quotations, and maintain quotation history efficiently.

---

## Features

- User Authentication System
- Session Management
- Dashboard with Statistics & Charts
- Customer Add / Edit / Delete
- Customer Photo Upload
- Quotation Generation System
- Dynamic Product Rows & Auto Total Calculation
- PDF / Print Quotation
- Quotation History Management
- Admin Controls
- Responsive UI Design

---

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- AJAX
